# Task 2 – Retrieval Augmented Generation (RAG) System

This directory contains the complete implementation of the RAG prototype for querying cyclone operation documents.

## Structure
- `architecture_diagram.pptx` / `architecture_diagram.png` – visual overview of the pipeline.
- `notes.md` – design notes, architecture decisions, and evaluation results.
- `prototype/` – runnable prototype with CLI, requirements, source code, sample docs, evaluation data, and tests.

See the individual README files for detailed usage instructions.
